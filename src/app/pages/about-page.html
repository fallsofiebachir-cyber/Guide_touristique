DOCUMENTATION DU PROTOTYPE

À propos du projet

Teranga Guides est une application pédagogique de gestion d’un répertoire fictif de guides touristiques au Sénégal.

01

Fonctionnalités réalisées

Consultation des fiches, recherche par nom, prénom ou spécialité, filtres par région et statut, ajout, modification et suppression avec validation du formulaire et confirmation avant suppression. Les préférences sont enregistrées localement dans le navigateur.

02

Limites actuelles

  • Les données sont conservées uniquement sur l’appareil et le navigateur utilisés. Il n’y a ni partage entre agents ni sauvegarde centralisée.
  • Le stockage local n’est pas sécurisé et les validations du navigateur peuvent être contournées. Cette démonstration ne doit pas recevoir de données personnelles réelles.
03

Évolution vers une API REST

Une prochaine version pourrait connecter le service Angular à une API REST via HttpClient : GET /api/guides, POST /api/guides, PUT /api/guides/:id et DELETE /api/guides/:id. Le serveur assurerait la validation définitive, l’authentification et les autorisations, tandis que l’interface afficherait les états de chargement et les erreurs réseau.
